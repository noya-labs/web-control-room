# Multi-Stream Viewing in One Browser Workspace

Watching several live streams often turns into a mess of tabs, windows and audio controls. **Web Control Room (WCR)** is designed to replace that tab-switching workflow with a customizable multi-tile dashboard.

## One screen instead of many tabs

With supported sources, WCR can be used as a visual workspace for:

- Multiple live video sources
- Live channels
- News and event monitoring
- Internet radio
- Widgets and information panels
- Captured web information

In Edit Mode, panels can be moved and resized to create side-by-side views, compact grids or layouts with one primary source and several secondary sources.

## Useful scenarios

### Sports and live events

Keep several supported live sources visible when multiple events are happening at the same time.

### News monitoring

Build a live-news control room with several channels or information sources visible together.

### Stream monitoring

Keep live streams and supporting information in one workspace rather than opening a separate tab for every source.

### Multitasking

Combine media with widgets, radio and web information when your workflow normally requires constant switching between browser tabs and apps.

## Browser-based, with optional capture tools

The core WCR experience runs in the browser. Optional WCR Capture components extend supported webpage capture and refresh workflows.

Source behavior varies because websites and streaming providers use different embedding, playback and browser-security policies.
