# IPTV Multiview: Watch Multiple Live Channels in One Dashboard

If you already have legitimate live-stream sources and want a cleaner way to keep several of them visible, **Web Control Room (WCR)** provides a browser-based multi-tile workspace for supported sources.

## What WCR is for

WCR focuses on the viewing and monitoring layer: arranging supported live channels, video sources, internet radio, widgets and other information into one customizable screen.

Typical uses include:

- Following several live sports or news feeds
- Building a 2×2-style multiview layout
- Keeping a primary stream large while monitoring secondary sources
- Creating a browser-based media wall
- Combining live video with radio, widgets and monitoring information

Tiles can be moved and resized in Edit Mode so the layout can match the task instead of forcing every source into a fixed player grid.

## Is WCR an IPTV provider?

No. **WCR does not sell or provide IPTV subscriptions or unauthorized streams.** It is a dashboard/interface for supported sources that you are able and authorized to access.

Playback availability depends on the source, provider, region and browser. Some providers also limit simultaneous playback.

## Why use a browser-based multiview?

A browser workspace is useful when the problem is not discovering one channel, but keeping multiple sources visible without constantly switching tabs or applications.

WCR also goes beyond a video-only grid: the same control room can include internet radio, widgets, captured web information and monitoring panels.
