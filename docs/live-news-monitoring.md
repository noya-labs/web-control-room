# Live News Monitoring Dashboard

When several stories are developing at once, repeatedly switching between news tabs makes it harder to maintain context. **Web Control Room (WCR)** can be configured as a browser-based live news and information monitoring dashboard.

## Build a visual news control room

A WCR workspace can combine supported:

- Live news and video sources
- Web information and captured regions
- Internet radio
- Widgets
- Information panels

The dashboard is moveable and resizable in Edit Mode, allowing you to keep high-priority sources prominent while secondary sources remain visible nearby.

## Who might use this workflow?

This type of layout can be useful for news watchers, researchers, creators, streamers and anyone following several live information sources at once.

Instead of a fixed television-style multiview, WCR is intended to combine different types of information in the same control room.

## Important source limitations

Individual live sources can become unavailable, restrict embedding, require authentication or vary by region and browser. WCR does not guarantee availability of third-party content and does not provide unauthorized streams.
